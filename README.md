# Replyline

基于 [Tendedero v1.5.0](https://github.com/alejandrobujan/tendedero/tree/cf87e6ebc275d4f2cc42900e55f88a52d3ce9e46) 的 Mac 微信客服素材工具。固定话术、图片与视频独立保存，原来的截图晾衣架继续负责临时截图。

公开仓库：[suguxiaojie/Replyline](https://github.com/suguxiaojie/Replyline)。

正式发行：[v0.3.6 Release](https://github.com/suguxiaojie/Replyline/releases/tag/v0.3.6)，包含中文更新说明、DMG 和 SHA-256 校验文件。

## 使用

当前版本为 Replyline 0.3.6（23），固定安装在 `/Applications/Replyline.app`，支持 macOS 14 及以上，包含 Apple silicon 和 Intel 二进制。预构建包使用 Apple Development 证书签名；源码构建产物为 `app/build/Replyline.app`，本地构建需配置自己的签名身份。

正式安装包为 [Replyline-0.3.6.dmg](https://github.com/suguxiaojie/Replyline/releases/download/v0.3.6/Replyline-0.3.6.dmg)，约 1.91 MiB，[SHA-256 校验文件](https://github.com/suguxiaojie/Replyline/releases/download/v0.3.6/Replyline-0.3.6.dmg.sha256)。DMG 内含 0.3.6 应用、Applications 快捷方式、安装说明与 MIT 许可，应用及镜像均使用现有证书签名，未做 Apple 公证。安装或更新前正常退出旧版，再打开 DMG，将 Replyline.app 拖入 Applications；已有旧版时选择替换，然后从「应用程序」启动。

首次安装时按需授予辅助功能权限，用于双击菜单栏空白处和截屏快捷键分类定位。开发机已验证同一签名身份及固定路径更新可保留授权；其他设备首次授权由各自系统管理。

1. 打开 Replyline 后，在菜单栏衣服图标中选择「管理常用素材…」，或按 `Control + Option + R`。
2. 点「新建话术」保存文字。图片可通过「导入图片」选择文件、直接拖进素材窗口，或按 `Command + V`／点「粘贴图片」导入；确认预览、标题和关键词后保存。
3. 勾选「置顶到晾衣架」，常用素材会长期挂在顶部。`Control + Option + T` 继续展开／收起原晾衣架，可在「设置 → 快捷键」中修改。
4. 点击绳上的话术复制完整文字；点击固定图片复制图片。回到微信后按 `Command + V`，检查内容后发送。
5. 从素材管理窗口复制时，窗口收起并尝试返回此前使用的应用；搜索后按回车复制第一条结果，按 Esc 返回。
6. 在绳上的临时图片右键选择「转为常用素材…」，会保存独立副本到素材库并默认置顶，原临时卡片取下。标题默认使用文件名，可在「管理常用素材…」编辑标题和关键词；录屏卡片不提供该入口。
7. 点击卡片右上角的眼睛图标开启预览，再点同一个图标可关闭；鼠标悬停不再展开。图片默认适应宽度，可滚动、缩放或切换「100%」。话术正文只读，可拖选部分文字后按 `Command + C` 或右键复制；选中后顶部按钮切换为「复制选中」，未选中时为「复制全文」。
8. 按住卡片正文左右拖动可更换位置，固定话术、图片、视频和临时卡片可以混合排序；在晾衣架内松手保存顺序，重启或编辑素材后保留。靠近左右边缘时自动滚动，能调整屏幕外的卡片。拖到架外仍按原来的文件／纯文字格式导出，取消或架外松手不提交架内排序。
9. 点「导入视频」选择 MP4、MOV 或 M4V，也可将视频文件拖入素材窗口；填写标题、关键词并保存，默认勾选「置顶到晾衣架」。管理窗口增加「视频」筛选，点击视频封面播放预览，点「复制」复制视频文件；编辑中可通过选择文件或拖入替换视频。

视频保存独立副本，不转码，移动或删除导入来源后仍可使用。晾衣架显示首帧、播放标识和固定素材图钉，沿用原卡片边框、夹子及排序动效；点击晾衣架上的视频卡片复制，点右上角预览图标用系统 Quick Look 播放，双击在默认应用打开。复制行为与在访达复制视频文件相同，再由用户回到微信粘贴并确认发送；也可直接拖出视频。微信最终显示为可播放视频还是文件附件，需要以当前微信的实际识别结果为准。

拖动采用「松夹 → 移动 → 归位 → 合夹」过渡：夹子以绳槽为轴张开，卡片脱离夹口并保留边框和阴影，邻近卡片以约 0.28 秒弹簧让位；系统拖影落位后，卡片回到夹口，稍后夹子弹簧合拢。交界处有小幅缓冲，避免反复交换位置。开启「减少动态效果」时取消新增位移和弹簧过渡。视觉排序不改变临时截图的加入时间及容量淘汰顺序，也不移动或删除素材文件。

话术编辑支持 `Command + C/V/X/A`（复制／粘贴／剪切／全选）、`Command + Z`（撤销）与 `Command + Shift + Z`（重做）。

晾衣架上的固定话术、图片和视频左下角有小图钉标识，临时卡片没有。图钉只标识固定素材，不是操作按钮；右上角预览、左上角取下、复制与拖拽保持原行为。

固定话术保留原始换行和空格。编辑窗口可修改标题、关键词和话术，或替换图片。图片编辑窗口也支持拖入和粘贴替换预览，保存后才更新库内图片。剪贴板同时含文字和图片时，`Command + V` 保持文字粘贴；点「粘贴图片」可明确导入其中的图片。固定图片长按仍调用系统 Markup 修改库内副本，固定话术长按打开素材编辑。

更新时，请先保存当前编辑内容、从菜单退出旧版，再使用下方安装流程替换固定路径的应用并启动。所有版本使用同一个素材目录，现有素材会继续载入。

## 菜单与设置

点击菜单栏衣服图标打开无箭头的原生玻璃面板，保留显示／隐藏晾衣架、管理常用素材、打开截图文件夹、清空临时截图、设置和退出六项操作，不再提供关于入口或面板。顶部显示固定素材与临时卡片数量；前两项为字号和行高略高的主要操作，所有操作采用统一列表，轻量分隔。配有统一的 SF Symbols 图标和快捷键，悬停显示选中反馈，按压时轻微收紧；按上下键选择、回车／空格执行、Esc 或同图标点击关闭，点击外部也会关闭。面板位置约束在图标所在屏幕内，没有临时内容时清空项置灰。晾衣架组合随用户配置更新。

点击「设置…」打开普通层级的原生设置窗口；Replyline 处于活动状态时也可按 `Command + ,`。左侧玻璃导航分为四页，选中项使用系统强调色；右侧使用轻量设置分组、分段选择和原生开关，统一字号、间距与控件对齐。视觉采用中性玻璃与单一系统强调色，没有渐变徽章、彩色大图标和装饰性副标题。修改后立即生效并保存，重新打开时沿用已有选择。

「菜单栏触发方式」与「卡片大小」采用滑动分段选择：选中块以约 0.28 秒弹簧过渡移动，带细边缘、轻阴影、悬停与按压反馈；聚焦后可用左右方向键切换，边界不循环。按钮遵循 macOS 焦点规则：系统开启控件键盘导航后，才能用 Tab 聚焦按钮；单纯点击按钮不保证键盘焦点。减少动态效果时取消滑动与缩放，沿用原设置绑定与持久化逻辑。参见 [Apple FocusInteractions.activate](https://developer.apple.com/documentation/swiftui/focusinteractions/activate)。

| 页面 | 配置 |
|---|---|
| 晾衣架 | 菜单栏触发方式、悬停等待时间、新卡片自动展开、全屏显示、卡片大小 |
| 截图与图片 | 系统截图保存方式、当前截图文件夹、自动收集剪贴板图片、额外图片文件夹、临时卡片保留数量 |
| 快捷键 | 显示／隐藏晾衣架组合、常用素材保留组合、macOS 截屏快捷键入口 |
| 通用 | 登录时启动 Replyline、播放交互音效 |

### 界面与动效

菜单与设置参考 Codex Monitor 的原生容器实现。macOS 26 及以上使用 NSGlassEffectView 的 clear 样式，玻璃内只叠中性的半透明衬底与细边缘；旧系统回退 NSVisualEffectView 的 behindWindow 混合。菜单使用可接收键盘、不会成为主窗口的无边框 NSPanel；玻璃视图保留复用，窗口淡入约 0.12 秒。设置侧栏选中背景连续移动，页面采用约 0.34 秒的无回弹弹簧过渡，触发方式相关配置采用约 0.3 秒过渡，按压轻微缩小并降低透明度。读取系统「减少动态效果／降低透明度」偏好：减少动态效果时取消位移与缩放，降低透明度时动态切换实色容器。晾衣架原展开、飞入、摆动与落下参数保持，拖动排序新增独立的让位和夹子开合过渡。

玻璃衬底按用户最新反馈提高遮挡：浅色衬底不透明度为 90%，深色为 88%，减少背后文字干扰；文字和控件透明度保持原样，仍保留轻微透光与原生玻璃边缘。这些比例仅表示衬底，不代表系统玻璃合成后的整体透明度。

离屏预览以中性背景展示控件布局，不能作为实际桌面玻璃的验证证据。设计参考 [Apple macOS 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/) 与 [侧栏指南](https://developer.apple.com/design/human-interface-guidelines/sidebars)。

### 展开方式

「菜单栏触发方式」为单选：

- 「不启用」：菜单栏手势关闭，菜单与快捷键仍能展开。
- 「悬停菜单栏」：保留原来的悬停方式，等待时间可选 0.25、0.5、1 或 2 秒，默认 0.25 秒。点击菜单栏后，指针离开菜单栏才重新允许悬停展开。
- 「双击菜单栏空白处」：只有连续两次左键点击同屏空白处才展开，菜单文字和状态图标不触发。双击速度遵循系统设置。

选择悬停后显示等待时间；选择双击后显示辅助功能权限状态和「去开启…」按钮。双击只读识别菜单栏空白处，权限不足或 AX 无法识别时不展开。真实系统权限由用户授予，未授权时也可使用悬停、菜单或快捷键。当前稳定签名构建已完成跨版本授权保留验证。

「新卡片加入时自动展开」为独立开关，控制新截图、剪贴板图片和新增置顶素材的短暂展开；编辑已有素材不会触发新卡片展开。「允许在全屏应用中显示」独立控制全屏场景。已有菜单栏手势选择继续沿用。

### 截图与图片

- 「保持系统截图保存位置」沿用系统目录并收集新截图。「保存到 Replyline」把系统截图保存到应用目录，并关闭系统浮动缩略图；关闭此选项或正常退出后恢复原设置。
- 「自动收集剪贴板图片」开启后持续收集新复制的图片，不自动收集普通文字；手动粘贴到常用素材仍在素材窗口完成。
- 「额外图片文件夹」使用路径列表，可添加／移除，最多 3 个目录。移除只停止收集，不删除文件。
- 「临时卡片保留数量」可选适应屏幕、25、50 或 100 张，只限制临时卡片。超出容量时，Replyline 截图目录的旧文件移到废纸篓，外部文件只从晾衣架取下，固定素材保留。

「清空临时截图…」先显示数量及文件去留，再确认执行。只清理确认时列出的卡片，等待确认期间新加入的卡片保留；常用素材始终不受影响。

### 快捷键

「设置 → 快捷键」直接显示当前组合：

- 「显示／隐藏晾衣架 → 修改…」录制组合；按 Esc 取消、按 Delete 禁用，录制期间暂停应用热键。常用素材的 `Control + Option + R` 和设置的 `Command + ,` 为保留组合，其他注册失败的组合保留原值并提示。
- 「管理常用素材」固定为 `Control + Option + R`。
- 「系统截屏快捷键 → 设置截屏快捷键…」打开系统键盘快捷键窗口，并利用 Replyline 已有的辅助功能授权自动选中「截屏」。定位以系统本地化分类标签为依据，选择其所属行并确认选中状态；没有权限或系统 UI 无法定位时提示手动选择。Replyline 只切换分类，快捷键组合由用户在系统窗口中双击修改。已在本机 macOS 27 验证正常打开，以及窗口已经停在「修饰键」时的重复跳转，导航前后的系统快捷键配置一致。

上游版权声明与完整许可保留在源码 LICENSE、应用的 `Contents/Resources/LICENSE.txt` 和安装包中。

### 授权开关开启，但应用仍显示未授权

旧版本的本地 ad hoc 签名身份包含二进制哈希，重新构建后可能与系统保存的授权记录不匹配。2026-10-11 已从 TCC 日志确认一次此类问题：系统的 Replyline 开关开启，但日志报代码要求不匹配，应用内显示「去开启」。正常重启未解决。

经用户确认，仅重置 Replyline 的 Accessibility 记录并重新授权，旧版双击展开恢复。此次切换到开发者签名时，在「系统设置 → 隐私与安全 → 设备控制和数据访问」（旧系统为「辅助功能」）重新添加固定位置的 `/Applications/Replyline.app`，完成一次性授权。重置授权需要明确确认，不作为应用自动行为，也不在正常更新流程中执行。

现在构建固定使用同一 Apple Development 证书，bundle ID 保持 `local.coverai.Replyline`，安装路径固定为 `/Applications/Replyline.app`。安装脚本要求新版满足旧版的 designated requirement，身份不兼容时拒绝替换。已验证 0.2.4 与 0.2.5 的代码哈希不同但身份要求一致，并实际更新后确认有效授权保留。证书更换、撤销、系统权限策略改变仍需重新核验，不能保证任何未来变化都免于重授。代码身份与跨版本权限匹配机制见 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

## 文件去留

- 固定图片导入时复制原文件，移动或删除导入来源不影响库内素材。
- 固定素材的角落按钮只取消置顶。清空临时截图、降低截图容量和新增截图都不会删除固定素材。
- 固定图片拖出只允许复制，库内副本保持原位；固定话术拖出提供纯文字。
- 固定视频复制／拖出提供原视频文件，只允许复制；清空临时卡片、容量淘汰和取消置顶不会删除视频副本。视频校验与文件复制异步完成，首帧缓存用于素材列表和晾衣架，保存失败清理本次生成文件并保留原素材。
- 从素材库移除需要确认，库内文件移到废纸篓；导入来源不受影响。
- 普通截图继续遵循上游规则：接管截图目录中的图片淘汰／丢弃会进入废纸篓，外部目录中的图片普通取下只隐藏。
- 第一次打开时提供「将系统截图保存到 Replyline」提示；开启会修改系统截图保存位置和浮动缩略图设置，正常退出时恢复。

素材保存在 `~/Library/Application Support/Replyline/Library/`，其中 `library.json` 保存标题、话术、关键词和置顶状态，`Assets/` 保存独立副本。备份时复制整个 `Library/` 文件夹。素材保存在本地普通文件中，目录权限为 700，素材文件权限为 600。

0.3.6 兼容载入旧话术／图片库；保存了视频的素材库需要使用 0.3.6 或更高版本。旧版本无法识别视频类型时会停止写入，不应使用旧版编辑含视频的素材库。

## 原设计保留

晾衣架、玻璃边框、夹子闭合外观与尺寸、截图飞入与掉落、随机倾斜、弹簧摆动、微风、悬停缩放和展开／收起参数沿用上游。固定图片仍用原照片卡片，固定视频复用录屏卡片的首帧和播放标识；固定话术只替换卡片内的预览内容。拖动期间新增夹子张开／合拢和卡片让位，固定素材超过屏幕宽度时沿用原横向滚动并支持拖动至边缘自动滚动。图片／话术详情使用独立预览框，小卡片尺寸不变；预览在当前屏幕内定位，右侧卡片也不会把预览推出屏幕。图片／话术预览点击后保持展开，使用关闭按钮、Esc 或切到其他应用收起；显式关闭或按钮复制后尝试返回之前的应用。视频播放沿用系统 Quick Look。

新增管理窗口从菜单进入，使用普通窗口层级；切到微信等应用时按正常窗口顺序退到后面。顶部晾衣架继续使用悬浮层级。按上游许可，修改版采用 Replyline 名称和原创应用图标；菜单栏继续使用系统衣服符号。

```sh
swift test
swift scripts/check-strings.swift
scripts/build-app.sh
# 保存编辑内容并从菜单正常退出 Replyline 后安装。
scripts/install-app.sh
open /Applications/Replyline.app
```

发布打包在 release 构建完成后执行 `scripts/package-dmg.sh`，生成 `build/Replyline-版本号.dmg` 和对应 `.sha256`。应用与镜像必须使用相同的已批准证书；脚本拒绝覆盖已存在的同版本交付物。打包不调用访达自动化，也不改动系统设置。公开发布采用独立源码快照，安装包通过 GitHub Release 下载。

源码默认构建到 `app/build/Replyline.app`。验证不同版本时可设置 `REPLYLINE_VERSION`、`REPLYLINE_BUILD_NUMBER` 与 `REPLYLINE_APP_OUTPUT`，但日常安装位置始终为 `/Applications/Replyline.app`。安装脚本会拒绝替换正在运行的应用，先在目标卷暂存并校验新包，旧包保留在 `.tmp/stable-signing/install-backup.*/Replyline.app`；替换失败时尝试恢复旧包。

`app/.signing-identity` 保存已批准的 Apple Development 证书 SHA-1 指纹并由 Git 忽略；证书私钥保留在 macOS 钥匙串。可用 `SIGN_IDENTITY` 显式指定获批准的证书指纹，缺少配置或证书不可用时构建直接失败，不退回 ad hoc 签名。更换证书前需要重新验证跨版本身份兼容性。

本机当前证书有效至 2027-10-02，应用未嵌入 provisioning profile；本地原生 Mac 构建不采用免费 iOS 调试的 7 天 profile 续签流程。无需每 7 天重新打包，证书到期前仍应安排续期与身份兼容验证。没有新增第三方包依赖。Swift Package 的内部模块名仍为 Tendedero，以减少与上游无关的变更。
